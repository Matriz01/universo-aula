## Datos astronómicos

Los datos científicos proceden de fuentes de acceso público. Se requiere atribución explícita cuando se redistribuyan:

| Fuente                                                                             | Tipo de datos                         | Condiciones                                   |
| ---------------------------------------------------------------------------------- | ------------------------------------- | --------------------------------------------- |
| [NASA JPL Horizons](https://ssd.jpl.nasa.gov/horizons/)                            | Efemérides planetarias, órbitas       | Dominio público (NASA)                        |
| [NASA Planetary Fact Sheets](https://nssdc.gsfc.nasa.gov/planetary/factsheet/)     | Datos físicos planetarios             | Dominio público (NASA)                        |
| [IAU Resoluciones 5A y 6A (2006)](https://www.iau.org/administration/resolutions/) | Definición de planeta y planeta enano | Dominio público                               |
| [ESA Gaia](https://www.cosmos.esa.int/web/gaia)                                    | Catálogo estelar                      | CC BY-SA 3.0 IGO — citar misión y lanzamiento |
| [IAU Minor Planet Center](https://www.minorplanetcenter.net/)                      | Nomenclatura y objetos menores        | Citar IAU MPC                                 |

> **Nota ESA:** Las publicaciones y datos de ESA se publican habitualmente bajo CC BY-SA 3.0 IGO. Verificar la licencia concreta de cada conjunto de datos antes de redistribuir.
